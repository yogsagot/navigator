# העתקה והדבקה ב-Navigator

העתקה והדבקה בתוך תוכנת מסוף פשוטות פחות ממה שהן נראות. ל-Navigator אין חלון משלו, ולכן הוא אינו יכול לדבר
ישירות עם לוח הגזירים של שולחן העבודה כמו שעורך גרפי יכול. יש לו שתי דרכים להגיע אליו:

- **כלי לוח גזירים קטן** שמותקן במחשב שלכם (`xclip` או `xsel` ב-X11, ‏`wl-clipboard` ב-Wayland). Navigator מוסר
  את הטקסט לכלי, והכלי שם אותו בלוח הגזירים. זו הדרך האמינה.
- **המסוף שלכם.** Navigator יכול לבקש מהמסוף לשים טקסט בלוח הגזירים, או לקרוא אותו בחזרה. יש מסופים שעושים זאת,
  יש ששואלים אתכם קודם, ויש שמתעלמים מהבקשה לגמרי.

נוסף על כך, מסופים שומרים כמה מקשים לעצמם, כך שמקש שמעתיק במסוף אחד עלול לא להגיע ל-Navigator לעולם במסוף אחר.
המדריך הזה מסביר מה עובד איפה, ואיך להגדיר את הדברים כך שהכול פשוט יעבוד.

## התחלה מהירה

1. **התקינו כלי לוח גזירים.** בדקו באיזה סוג הפעלה של שולחן עבודה אתם עובדים:

   ```sh
   echo $XDG_SESSION_TYPE
   ```

   ואז התקינו את הכלי המתאים לו:

   | הפעלה   | Debian, ‏Ubuntu, ‏Mint          | Fedora                         |
   |-----------|-------------------------------|--------------------------------|
   | `x11`     | `sudo apt install xclip`      | `sudo dnf install xclip`       |
   | `wayland` | `sudo apt install wl-clipboard` | `sudo dnf install wl-clipboard` |

   `xsel` עובד טוב כמו `xclip`; צריך רק אחד מהם.

2. **בעורך, השתמשו ב-Ctrl+C, ‏Ctrl+X ו-Ctrl+V.** הם עובדים בכל מסוף שנבדק עד כה.

3. **אם אתם משתמשים ב-Ghostty**, הוסיפו את השורות האלה ל-`~/.config/ghostty/config` (או `config.ghostty`) והפעילו
   את Ghostty מחדש:

   ```
   keybind = ctrl+insert=unbind
   keybind = shift+insert=unbind
   ```

זה כל מה שרוב האנשים צריכים. שאר המדריך הוא הפרטים שמאחורי זה. מריצים את Navigator בשרת דרך ssh? ראו
[בשרת מרוחק דרך ssh](#בשרת-מרוחק-דרך-ssh).

## מקשים

המקשים תלויים במקום שבו אתם נמצאים ב-Navigator.

### בעורך (F4)

| כדי                                         | לחצו                               |
|--------------------------------------------|-------------------------------------|
| להעתיק                                       | **Ctrl+C**, ‏Ctrl+Ins או Ctrl+Alt+C  |
| לגזור                                        | **Ctrl+X**, ‏Shift+Del או Ctrl+Alt+X |
| להדביק                                      | **Ctrl+V**, ‏Shift+Ins או Ctrl+Alt+V |
| למחוק את הבלוק המסומן בלי להעתיק אותו | Ctrl+Del                            |

ארבעתם נמצאים גם בראש התפריט **עורך** (בשורת התפריטים כל עוד עורך פעיל).

העתקה וגזירה פועלות על הבלוק המסומן. כדי לסמן בלוק, החזיקו Shift תוך כדי הזזת הסמן, או גררו עם העכבר.

יש שלוש ערכות מקשים כי אין ערכה אחת שעובדת בכל מקום:

- **Ctrl+Ins / Shift+Del / Shift+Ins** הם המקשים המקוריים של DOS Navigator. יש מסופים ששומרים את Ctrl+Ins
  ו-Shift+Ins לעצמם (ראו [הערות על מסופים](#הערות-על-מסופים)).
- **Ctrl+C / Ctrl+X / Ctrl+V** הם המקשים שכל תוכנה אחרת משתמשת בהם.
- **Ctrl+Alt+C / Ctrl+Alt+X / Ctrl+Alt+V** הם ערכה רזרבית, למקרה שהמסוף או שולחן העבודה שלכם לוקחים את שתי
  האחרות.

> **מגיעים מ-DOS Navigator?** העורך שלו השתמש ב-Ctrl+C, ‏Ctrl+X ו-Ctrl+V ל-Page Down, לסמן למטה ולמעבר בין הוספה
> לדריסה (מקשי WordStar). Navigator משתמש בהם ללוח הגזירים במקום. PgDn, ‏Down ו-Ins עדיין עושים את התפקידים האלה.
> גם שאר מקשי WordStar ‏(Ctrl+K…, ‏Ctrl+Q…, ‏Ctrl+E, ‏Ctrl+S וכן הלאה) אינם מוקצים כברירת מחדל; טענו את
> `keybindings_wordstar.ini` דרך אפשרויות > תצורה > קיצורי מקשים > טען כדי לקבל אותם בחזרה, או את
> `keybindings_dn151.ini` כדי לקבל גם את Ctrl+C/X/V של DN.

### בשורות קלט של תיבות דו-שיח ובשורת הפקודה

| כדי    | לחצו                                                                                                |
|-------|------------------------------------------------------------------------------------------------------|
| להעתיק  | Ctrl+Ins: מעתיק את הבחירה, או את כל השורה אם דבר אינו נבחר. Ctrl+C מעתיק בחירה. |
| לגזור   | Shift+Del                                                                                            |
| להדביק | Shift+Ins או Ctrl+V                                                                                  |

כדי לבחור טקסט בשורה, החזיקו Shift והזיזו את הסמן, או גררו עם העכבר.

בשורת הפקודה שמתחת ללוחות, **Ctrl+E ו-Ctrl+X הולכים אחורה וקדימה בהיסטוריית הפקודות**, ולכן Ctrl+X אינו גוזר שם.

### במסוף (Ctrl+O)

בחרו טקסט בגרירה עם העכבר, או בלחיצה כפולה על מילה. ואז:

| כדי    | לחצו                                                                   |
|-------|-------------------------------------------------------------------------|
| להעתיק  | Ctrl+Ins, או Ctrl+C כשאין תוכנה שרצה                          |
| להדביק | מקש ההדבקה של המסוף שלכם (בדרך כלל Ctrl+Shift+V), או לחיצה אמצעית |

כשתוכנה רצה במסוף, Ctrl+C הולך לתוכנה הזו (בדרך כלל כדי לעצור אותה), כצפוי. גם טקסט שמדביקים הולך לתוכנה שרצה.

### דרכים אחרות להעתיק

- **מחשבון**: הכפתור *העתק* (קלאסי) ו*מחשבון > העתק* (בכל הפנים) שמים את התוצאה בלוח הגזירים.
- **לוכד המסך** (Alt+Shift+Ins): הזיזו את האזור ושנו את גודלו בחצים וב-Shift+חצים, ואז לחצו Enter כדי להעתיק את
  החלק הזה של המסך כטקסט -- או גררו את האזור עם העכבר, והוא מועתק כשמשחררים. Esc או לחיצה ימנית יוצאים בלי להעתיק.
- **סכום עמודה** (Alt+Ins בעורך, כשבלוקים אנכיים מופעלים): מחבר את המספרים שבעמודה המסומנת ושם את הסכום בלוח
  הגזירים.

## העכבר והבחירה הראשית

בלינוקס יש בעצם שני לוחות גזירים:

- **לוח הגזירים**, שמתמלא בהעתקה ונקרא בהדבקה;
- **הבחירה הראשית** (primary selection), שמתמלאת פשוט בבחירת טקסט ומודבקת בלחצן האמצעי של העכבר.

Navigator הולך לפי אותה מוסכמה. כשגוררים מעל טקסט בעורך, במסוף או בשורת קלט, הוא הופך לבחירה הראשית, ו**לחיצה
אמצעית** מדביקה את הבחירה הראשית. **לחיצה כפולה** בוחרת מילה.

מכיוון ש-Navigator משתמש בעכבר בעצמו, הבחירה בעכבר של המסוף עצמו אינה בהישג יד כל עוד Navigator רץ. כדי להשתמש
בה בכל זאת (כדי לבחור טקסט בדרך של המסוף, או להגיע לתפריט הלחיצה הימנית שלו), **החזיקו Shift** בזמן הגרירה או
הלחיצה. זה עובד ברוב המסופים.

## ההדבקה של המסוף עצמו

למסוף שלכם יש מקש הדבקה משלו, בדרך כלל **Ctrl+Shift+V**, ופריט Paste בתפריט שלו. את ההדבקה הזו עושה המסוף: הוא
מקליד את לוח הגזירים של שולחן העבודה לתוך Navigator כאילו הקלדתם אותו. זה עובד בלי קשר להגדרות של Navigator ובין
שכלי לוח גזירים מותקן ובין שלא.

זו הסיבה שהדבקה של טקסט שהועתק בתוכנה אחרת יכולה לעבוד מצוין בזמן שהעתקה *מתוך* Navigator לא עובדת: הכיוון הראשון
הוא התפקיד של המסוף, השני של Navigator.

## ההגדרה "שימוש בלוח המערכת"

**אפשרויות > תצורה > הגדרות מערכת > שימוש בלוח המערכת**

- **מופעל** (ברירת המחדל): העתקה שמה טקסט בלוח הגזירים של שולחן העבודה, כך שתוכנות אחרות יכולות להדביק אותו,
  והדבקה קוראת את לוח הגזירים של שולחן העבודה.
- **כבוי**: Navigator מחזיק לוח גזירים פרטי משלו, כמו ש-DOS Navigator עשה. שום דבר שמעתיקים אינו יוצא מ-Navigator.
  ההדבקה של המסוף עצמו (Ctrl+Shift+V) עדיין מכניסה את מה שיש בלוח הגזירים של שולחן העבודה.

Navigator תמיד שומר עותק משלו של הדבר האחרון שהעתקתם, לא משנה איך ההגדרה הזו קבועה.

## הערות על מסופים

יש מסופים ששומרים מקשים לעצמם עוד לפני ש-Navigator רואה אותם, והם נבדלים בשאלה אם הם מרשים לתוכנה להשתמש בלוח
הגזירים.

| מסוף                                  | לוקח לעצמו                              | מרשה ל-Navigator להשתמש בלוח הגזירים | מה לעשות                               |
|-------------------------------------------|-----------------------------------------------|----------------------------------|------------------------------------------|
| **Ghostty**                               | Ctrl+Ins, ‏Shift+Ins, ‏Shift+PgUp/PgDn/Home/End | העתקה: כן. הדבקה: שואל אתכם קודם | בטלו את הקצאת המקשים (להלן)                  |
| **xfce4-terminal, ‏GNOME Terminal, ‏Tilix** | Ctrl+Ins, ‏Shift+Ins (אי אפשר לשנות)       | לא                               | התקינו כלי לוח גזירים; השתמשו ב-Ctrl+C/X/V |
| **PyCharm ומסופים אחרים של JetBrains** | –                                             | לא                               | התקינו כלי לוח גזירים                 |

### Ghostty

כברירת מחדל Ghostty משתמש ב-**Ctrl+Ins** כדי להעתיק את הבחירה שלו וב-**Shift+Ins** כדי להדביק את הבחירה הראשית,
כך שהמקשים האלה לעולם אינם מגיעים ל-Navigator. הוא גם משתמש ב-Shift+PgUp, ‏Shift+PgDn, ‏Shift+Home ו-Shift+End
לגלילה, שהעורך צריך לסימון טקסט. הוסיפו את זה לקובץ התצורה של Ghostty והפעילו את Ghostty מחדש (סגרו כל חלון;
לשונית חדשה אינה מספיקה):

```
keybind = ctrl+insert=unbind
keybind = shift+insert=unbind
keybind = shift+page_up=unbind
keybind = shift+page_down=unbind
keybind = shift+home=unbind
keybind = shift+end=unbind
```

עדיין אפשר להעתיק ולהדביק ב-Ghostty עצמו עם Ctrl+Shift+C ו-Ctrl+Shift+V.

Ghostty מבקש רשות לפני שתוכנה רשאית *לקרוא* את לוח הגזירים. אם אין לכם כלי לוח גזירים מותקן, Navigator אינו מחכה
לתשובה שלכם ומדביק במקום את העותק האחרון שלו. כדי לתת ל-Navigator לקרוא את לוח הגזירים בלי לשאול, הוסיפו:

```
clipboard-read = allow
```

כדי לראות אילו מקשים Ghostty מקצה, הריצו `ghostty +list-keybinds --default`.

### xfce4-terminal, ‏GNOME Terminal, ‏Tilix

כל המסופים האלה בנויים על אותה ספרייה (VTE), שמטפלת בעצמה ב-**Ctrl+Ins** (העתקה) וב-**Shift+Ins** (הדבקת הבחירה
הראשית). אין הגדרה שמחזירה את המקשים האלה, ולכן השתמשו במקומם ב-**Ctrl+C / Ctrl+X / Ctrl+V** (או
Ctrl+Alt+C / X / V).

הם גם מתעלמים מבקשות של תוכנה להשתמש בלוח הגזירים, ולכן **נדרש כלי לוח גזירים** כדי להעתיק מתוך Navigator.

ב-**xfce4-terminal**, פתחו גם את *Edit > Preferences > Advanced* והפעילו את **Disable all menu access keys**
ואת **Disable menu shortcut key**. אחרת המסוף פותח את התפריטים שלו ב-Alt+E, ‏Alt+F, ‏Alt+V, ‏Alt+T, ‏Alt+B, ‏Alt+H
ו-F10, ש-Navigator משתמש בהם. אין לזה קשר ללוח הגזירים, אבל זה הדבר הבא שתיתקלו בו.

### PyCharm וסביבות פיתוח אחרות של JetBrains

המסוף המובנה מתעלם מבקשות של תוכנה להשתמש בלוח הגזירים, ולכן התקינו כלי לוח גזירים. כש*שימוש בלוח המערכת* כבוי,
העתקה והדבקה בתוך Navigator עובדות גם בלעדיו.

## בלי כלי לוח גזירים

Navigator עדיין עובד בלי כלי לוח גזירים מותקן:

- העתקה והדבקה **בתוך Navigator** עובדות. כשאי אפשר לקרוא את לוח הגזירים של שולחן העבודה, Navigator מדביק את
  העותק האחרון שלו. בפעם הראשונה שזה קורה, הודעה מציעה להתקין כלי לוח גזירים.
- העתקה **מתוך Navigator** לתוכנות אחרות עובדת רק אם המסוף שלכם מקבל את הבקשה (Ghostty כן; xfce4-terminal,
  ‏GNOME Terminal ו-PyCharm לא).
- הדבקה **לתוך Navigator** מתוכנות אחרות תמיד עובדת עם מקש ההדבקה של המסוף עצמו (Ctrl+Shift+V).

המלכודת היא שההדבקה של Navigator עלולה אז להדביק את מה *שהעתקתם לאחרונה ב-Navigator*, ולא את מה שהעתקתם מאז
בתוכנה אחרת.

## בשרת מרוחק דרך ssh

כשמריצים את Navigator במחשב אחר דרך ssh, Navigator רץ *שם*, אבל לוח הגזירים שאתם רוצים נמצא במחשב *שלכם*. כלי לוח
גזירים בשרת אינו יכול לעזור לבדו: לשרת אין שולחן עבודה, ולכן ל-`xclip` שם אין לאן לשים את הטקסט. יש שלוש דרכים
לגשר על הפער, ואפשר להשתמש ביותר מאחת.

**העתקה והדבקה בתוך Navigator תמיד עובדות**, לא משנה מה הגדרתם. כשאי אפשר להגיע ללוח הגזירים שבמחשב שלכם,
Navigator מדביק את העותק האחרון שלו.

### הדבקה פנימה: מקש ההדבקה של המסוף

ההדבקה של המסוף עצמו (בדרך כלל **Ctrl+Shift+V**, או התפריט שלו) מקלידה את לוח הגזירים המקומי שלכם לתוך הפעלת
ה-ssh. היא אינה דורשת שום הגדרה והיא הדרך המהירה ביותר להכניס טקסט מהמחשב שלכם, כי שום דבר אינו צריך לנסוע חזרה
כדי להביא אותו. מקשי ההדבקה של Navigator עצמו נחוצים רק לטקסט שהעתקתם בתוך Navigator.

### העתקה החוצה: המסוף שלכם (OSC 52)

Navigator מבקש מהמסוף המקומי שלכם לשים טקסט שהועתק בלוח הגזירים שלכם, בעזרת תכונת מסוף שנקראת OSC 52. הבקשה
נוסעת בחיבור ה-ssh כמו כל פלט אחר, ולכן היא אינה צריכה דבר בשרת. האם זה עובד תלוי במסוף ה**מקומי** שלכם:

| מסוף                                  | העתקה החוצה                                         |
|-------------------------------------------|--------------------------------------------------|
| Ghostty, ‏WezTerm, ‏foot                    | עובד                                            |
| kitty                                     | עובד (`clipboard_control` חייב להרשות `write-clipboard`, כמו שהוא עושה כברירת מחדל) |
| Alacritty                                 | עובד (`osc52` ב-`[terminal]` אסור שיהיה `Disabled`) |
| xfce4-terminal, ‏GNOME Terminal, ‏Tilix     | לא נתמך; השתמשו בהעברת X11 (להלן)        |
| PyCharm ומסופים אחרים של JetBrains     | לא נתמך                                    |

כדי לבדוק את המסוף שלכם בלי Navigator, הריצו את זה בשרת ואז הדביקו במחשב שלכם:

```sh
printf '\e]52;c;%s\a' "$(printf hello | base64)"
```

אם `hello` מגיע, גם העתקה מתוך Navigator עובדת. אם לא, המסוף שלכם מתעלם מ-OSC 52.

OSC 52 יכול גם *לקרוא* את לוח הגזירים, אבל רוב המסופים מסרבים או שואלים אתכם קודם, ולכן להדבקה פנימה השתמשו במקש
ההדבקה של המסוף.

### לשני הכיוונים: העברת X11

ssh יכול להעביר חיבורי X11 מהשרת בחזרה למחשב שלכם. השרת מקבל אז `DISPLAY` שמוביל לשולחן העבודה שלכם, וכלי לוח
הגזירים של Navigator בשרת מגיע ללוח הגזירים **שלכם**, להעתקה ולהדבקה, לא משנה מה המסוף שלכם תומך.

צריך:

- **במחשב שלכם**: שרת X. לכל שולחן עבודה של X11 יש אחד; ב-Wayland, ‏XWayland עושה את העבודה ומשתף את לוח הגזירים
  עם תוכנות Wayland.
- **בשרת**: `xclip` (או `xsel`) ו-`xauth` (`sudo apt install xclip xauth`, או `sudo dnf install xclip
  xorg-x11-xauth`), ו-`X11Forwarding yes` ב-`/etc/ssh/sshd_config`, שרוב ההפצות כבר קובעות. בדקו עם
  `sudo sshd -T | grep -i x11forwarding`.

ואז התחברו עם **`-Y`**:

```sh
ssh -Y user@server
```

בפעם הראשונה ייתכן שתראו `/usr/bin/xauth: file /home/user/.Xauthority does not exist`. זה לא מזיק: `xauth` יוצר
את הקובץ וההודעה לא חוזרת. כדי לבדוק שזה עובד:

```sh
echo $DISPLAY                            # something like localhost:10.0
echo hello | xclip -selection clipboard  # then paste on your computer
```

הפעילו את Navigator מאותה הפעלה, כש*שימוש בלוח המערכת* מופעל. כדי להעביר X11 בכל פעם שמתחברים לשרת הזה, הוסיפו את
זה ל-`~/.ssh/config` במחשב שלכם:

```
Host server
    ForwardX11 yes
    ForwardX11Trusted yes
```

דברים שכדאי לדעת:

- **אבטחה.** `-Y` נותן לשרת אמון בהפעלת ה-X שלכם: תוכנה בו, או כל מי שיש לו root שם, יכולים לקרוא את ההקשות, המסך
  ולוח הגזירים שלכם כל עוד אתם מחוברים. השתמשו בזה רק עם שרתים שאתם סומכים עליהם. `-X` הפשוט מגביל את השרת, אבל
  ההגבלה עלולה גם למנוע מ-`xclip` לקרוא את לוח הגזירים שלכם, כך שייתכן שהדבקה לא תעבוד.
- **להדבקה יש השהיה קצרה.** כל הדבקה של Navigator מפעילה את `xclip` בשרת, שמביא את לוח הגזירים שלכם דרך הרשת. כמה
  מאות אלפיות שנייה הן דבר רגיל דרך האינטרנט. מקש ההדבקה של המסוף שלכם חוסך את הנסיעה הלוך ושוב. אם ההבאה לוקחת
  יותר משתי שניות, Navigator מוותר ומדביק את העותק האחרון שלו.
- **עותק עלול להיעלם כשמתנתקים.** `xclip` ממשיך להגיש את הטקסט שהועתק מהשרת, ולכן הדביקו אותו במקום כלשהו במחשב
  שלכם לפני שאתם מתנתקים אם תצטרכו אותו אחר כך.

### בתוך tmux או screen

בתוך **tmux**, תנו ל-tmux להעביר את בקשות ההעתקה של OSC 52 למסוף שלכם בהוספת זה ל-`~/.tmux.conf`:

```
set -g set-clipboard on
```

העברת X11 עובדת ב-tmux כל עוד הפעלת ה-tmux התחילה מהפעלת ssh עם העברה. הפעלה שנוצרה קודם, או שחוברה מחדש מחיבור
חדש, שומרת על ה-`DISPLAY` הישן. הריצו שם `export DISPLAY=...` עם הערך החדש, או הפעילו את Navigator בחלון tmux חדש.

אם מסוף מדפיס זבל כשמעתיקים, אפשר לכבות את הדרך דרך המסוף בהפעלת Navigator עם `NAVKIT_CLIPBOARD=off nav`.

## פתרון בעיות

**העתקה לא עושה כלום, או שהטקסט לא מגיע לתוכנות אחרות.**
אין כלי לוח גזירים מותקן, והמסוף שלכם מתעלם מהבקשה של Navigator. התקינו `xclip` או `wl-clipboard`
(ראו [התחלה מהירה](#התחלה-מהירה)).

**הדבקה מדביקה טקסט ישן, לא את מה שהעתקתי עכשיו בתוכנה אחרת.**
Navigator לא הצליח לקרוא את לוח הגזירים של שולחן העבודה והשתמש בעותק האחרון שלו. התקינו כלי לוח גזירים. ב-Ghostty
אפשר גם לקבוע `clipboard-read = allow`. עד אז, השתמשו במקש ההדבקה של המסוף שלכם (Ctrl+Shift+V).

**Shift+Ins מדביק משהו שונה מ-Ctrl+V.**
המסוף שלכם תפס את Shift+Ins והדביק את *הבחירה הראשית* (הטקסט האחרון שסימנתם במקום כלשהו) במקום את לוח הגזירים.
ב-Ghostty, בטלו את ההקצאה שלו כמו שמוצג למעלה. ב-xfce4-terminal וב-GNOME Terminal, השתמשו ב-Ctrl+V.

**מקש לא עושה שום דבר.**
המסוף או שולחן העבודה שלכם כנראה שומרים את המקש הזה. מתוך עותק של קוד המקור של Navigator אפשר לראות מה באמת מגיע:

```sh
./venv/bin/python tools/keyprobe.py
```

לחצו על המקש. אם שום דבר לא מודפס, המסוף שמר אותו. לחצו `q` פעמיים כדי לצאת. השתמשו במקש אחר מאלה שמופיעים
למעלה, או הקצו מקש משלכם (הסעיף הבא).

**דרך ssh, טקסט שהועתק לא מגיע למחשב שלי לעולם.**
לשרת אין שולחן עבודה, והמסוף המקומי שלכם מתעלם מ-OSC 52. השתמשו בהעברת X11 (`ssh -Y`), או במסוף שתומך ב-OSC 52;
ראו [בשרת מרוחק דרך ssh](#בשרת-מרוחק-דרך-ssh).

**דרך ssh, הדבקה לוקחת רגע.**
עם העברת X11, כל הדבקה מביאה את לוח הגזירים שלכם דרך הרשת. השתמשו במקש ההדבקה של המסוף שלכם (Ctrl+Shift+V) לטקסט
מהמחשב שלכם; הוא אינו צריך את הנסיעה הלוך ושוב.

**זה עובד במסוף אחד ולא באחר.**
זה צפוי. בדקו את המסוף הזה ב[הערות על מסופים](#הערות-על-מסופים).

## שינוי המקשים

כל מקש אפשר לשנות ב-**אפשרויות > תצורה > קיצורי מקשים**, או ב-`~/.config/navigator/keybindings.ini`. לפקודה יכולים
להיות כמה מקשים, מופרדים בפסיקים:

```ini
clipboard_cut = shift+delete, ctrl+x, ctrl+alt+x
clipboard_copy = ctrl+insert, ctrl+c, ctrl+alt+c
clipboard_paste = shift+insert, ctrl+v, ctrl+alt+v
```

מקש יכול להשתייך רק לפקודה אחת באותו מקום. כדי לתת את Ctrl+C למשהו אחר בעורך, הסירו אותו קודם מ-`clipboard_copy`.

Navigator כותב את הקובץ עם כל ברירות המחדל שלו בהפעלה הראשונה, ושומר את מה שכתוב בו. אם הקובץ שלכם ישן יותר
משינוי בברירות המחדל, הוא שומר את המקשים הישנים שלכם. בחרו את הפקודה בתיבת קיצורי המקשים ולחצו **מקורי** כדי לקבל
את החדשים.
