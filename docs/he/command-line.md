# הפעלת Navigator

הפקודה היא `nav`:

```sh
nav [LEFT] [RIGHT] [options]
```

`LEFT` ו-`RIGHT` הן התיקיות ששני הלוחות נפתחים בהן. עם אחת, שני הלוחות נפתחים בה; בלי אף אחת, שניהם נפתחים
בתיקייה הנוכחית. כל אחת מהן יכולה להיות כתובת של מקום שאינו הדיסק, כמו `sftp://user@host/dir`, `ftp://host/`,
`smb://host/share` או `s3://s3.amazonaws.com/bucket`; ראו [מקומות שאינם הדיסק](drives.md).

אפשרות שניתנה בשורת הפקודה תקפה להפעלה הזו בלבד. היא גוברת על [ההגדרות](settings.md) ולעולם אינה נכתבת
חזרה אליהן.

## קבצים ומקומות

| אפשרות | מה היא עושה |
|---|---|
| `-e FILE`, `--edit FILE` | פותחת את הקובץ ב[עורך](editor.md) בהתחלה. תנו אותה יותר מפעם אחת ליותר קבצים. שם שעדיין אינו קיים נוצר כשאתם שומרים |
| `--config PATH` | קוראת ושומרת את ההגדרות בקובץ אחר מ-`~/.config/navigator/navigator.ini` |
| `--database PATH` | שומרת את ההיסטוריות והסימניות בקובץ אחר מ-`~/.local/state/navigator/navigator.db` |
| `--version` | מדפיסה את הגרסה ואיזה עותק של Navigator מותקן, ויוצאת |

הקבצים שנמצאים לצד `navigator.ini` -- [תפריט המשתמש ושיוכי הקבצים](user-menu.md), קיצורי המקשים, לוחות הצבעים --
אינם עוברים עם `--config`: הם נשארים ב-`~/.config/navigator`.

## צבעים ותווים

| אפשרות | מה היא עושה |
|---|---|
| `--theme NAME` | משתמשת בערכת צבעים אחרת |
| `--list-themes` | מדפיסה את שמות ערכות הצבעים, ויוצאת |
| `--palette dos` | מציגה כל צבע כפי שכרטיס ה-VGA של DOS Navigator הציג אותו, בלי קשר לערכת הצבעים של המסוף עצמו |
| `--palette terminal` | משאירה את שישה-עשר הצבעים לערכת הצבעים של המסוף עצמו |
| `--reprogram-palette` | מגדירה את שישה-עשר הצבעים של המסוף לאלה של DOS כל עוד Navigator רץ, למסוף שאי אפשר לתת לו צבעים בדרך אחרת |
| `--colors DEPTH` | כמה צבעים המסוף מציג: `mono`, `8`, `16`, `256` או `truecolor`. `auto` מחליט לפי `$COLORTERM` ו-`$TERM` |
| `--glyphs SET` | אילו תווים הגופן של המסוף מצייר: `ascii` מצייר מסגרות ב-`+` וב-`-`, `unicode` מצייר תיבות, `nerd` מוסיף סמל לצד כל שם קובץ עבור Nerd Font. `auto` מנחש |
| `--marks LOOK` | איך נראים תיבות סימון וכפתורי בחירה: `dos` הוא `[X]` ו-`(•)`, `brackets` הוא `[✓]` ו-`(●)`, `boxes` בלי סוגריים |
| `--charset NAME` | ערכת התווים של מסוף שאינו UTF-8, כמו `koi8-r`, `cp866` או `iso8859-2`. בלעדיה משתמשים בזו של האזור (locale) |
| `--graphics HOW` | איך המציג מצייר תמונה: `kitty`, `sixel`, או `none` כדי להציג את הבתים שלה. בלעדיה שואלים את המסוף |
| `--no-dim-modal` | משאירה את מה שמאחורי תיבת דו-שיח בצבע מלא, במקום דהוי; `--dim-modal` מחזירה את ההדהיה |

ב[מקשים וצבעים](customizing.md#צבעים) יש עוד על ערכות נושא.

## שפה וכיוון

| אפשרות | מה היא עושה |
|---|---|
| `--language CODE` | השפה של הכיתובים וההודעות, כמו `lv`, `ru`, `ja` או `en`. בלעדיה משתמשים ב-*שפה* שבהגדרות, ואחרת ב-`$LANG` |
| `--direction auto` | משקפת את המסך כשהשפה נכתבת מימין לשמאל, כמו עברית או ערבית. בלי האפשרות משתמשים ב-*כיוון טקסט* שבהגדרות, שערכו ההתחלתי הוא זה |
| `--direction rtl` | משקפת את המסך בכל שפה, כך שהוא נקרא מימין לשמאל |
| `--direction ltr` | לעולם אינה משקפת את המסך |
| `--bidi app` | Navigator מסדר בעצמו טקסט מימין לשמאל לפני שהוא שולח אותו. בלי האפשרות המסוף מזוהה והדרך הנכונה נבחרת |
| `--bidi words` | כל מילה מימין לשמאל נשלחת הפוכה, למסוף כמו kitty שהופך אותה שוב |

אותן בחירות נמצאות בעמוד [ממשק](settings.md#ממשק) של ההגדרות.

## כשמשהו משתבש

| אפשרות | מה היא עושה |
|---|---|
| `--on-error dialog` | שגיאה בלתי צפויה מציגה תיבה עם הפרטים שלה, ואפשר להמשיך |
| `--on-error crash` | שגיאה בלתי צפויה סוגרת את Navigator ומדפיסה את הפרטים שלה |

בשני המקרים השגיאה נוספת ל-`errors.log`, לצד מסד הנתונים: ב-`~/.local/state/navigator`, או בתיקייה ש-`--database`
מציינת. בעמוד [מערכת](settings.md#מערכת) של ההגדרות יש אותה בחירה.

## בתוך Navigator

הקלדת `nav` בשורת הפקודה של Navigator עצמו אינה מפעילה עותק שני: היא אומרת ש-Navigator כבר רץ ו-`Ctrl+O` חוזר
אליו.
