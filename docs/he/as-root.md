# עבודה כ-root

כשפעולה בדיסק שלכם נדחית משום שאין לכם הרשאה, Navigator יכול לבצע אותה שוב כ-root. הוא מבקש את הסיסמה שלכם
דרך `sudo`, או נותן ל-`pkexec` לבקש אותה. הסיסמה אינה נשמרת, אבל גישת root נשארת פתוחה כמה דקות אחרי הפעולה
האחרונה שלה, ונסגרת כש-Navigator יוצא.

## השאלה כ-root

כשהעתקה, העברה, מחיקה, שינוי שם, יצירת תיקייה או קישור, שינוי מאפיינים, שמירה בעורך או קריאת קובץ נדחים, ההודעה
מציעה *כ-root*: לצד *דלג* ו-*ביטול* כשיש עוד קבצים להמשיך איתם, כמו בהעתקה או במחיקה, ולצד *ביטול* בלבד בכל מקרה
אחר. בחרו בה, תנו את הסיסמה שלכם, והפעולה מתבצעת שוב כ-root -- וכך גם כל פעולה מאוחרת יותר של אותה פעולה, בלי
לשאול שוב.

כניסה לתיקייה שאינכם רשאים לקרוא שואלת את אותה שאלה. אחרי שעניתם, הלוח מציג את התיקייה כ-root: הנתיב שלה מוצג
כ-`root:///path`, והעתקה, מחיקה, הצגה, עריכה וכל השאר פועלים שם כמו בכל מקום אחר. פקודות שהיו רצות בשמכם ולא
כ-root, כמו *פלט פקודה ללוח* ו-*הצג קישורים קשיחים*, מוצגות שם באפור. עלייה לתיקייה שאתם רשאים לקרוא מחזירה את
הלוח לדיסק.

## גישת root

*כלים > הפעל גישת root* מבקש את הסיסמה פעם אחת ומשאיר את גישת root פתוחה: עד שהיא נסגרת, תיקייה שאינכם רשאים
לקרוא נפתחת כ-root בלי לשאול, ו[המסוף](console.md) מריץ מעטפת root שעוקבת אחרי הלוח. כל עוד היא פתוחה, *ROOT*
מוצג בשורת התפריט לצד השעון, ובשורת המקשים כששורת התפריט מוסתרת או כשהמסוף מוצג.

*כלים > סגור גישת root* -- אותו פריט, ששמו משתנה כל עוד גישת root פתוחה -- או לחיצה על *ROOT* סוגרים אותה:
הלוחות שעיינו כ-root חוזרים לדיסק, והמסוף חוזר למעטפת שלכם.

גישת root נסגרת גם מעצמה אחרי שלא השתמשו בה זמן מה, ותמיד כש-Navigator יוצא.

## הגדרות

בעמוד [מערכת](settings.md#מערכת) של ההגדרות:

- *גישת root* בוחר איך להפוך ל-root: *אוטומטי* משתמש ב-`sudo`, ואחרת ב-`pkexec`; *sudo* ו-*pkexec* משתמשים
  בתוכנית הזו; *לא להציע* מכבה את האפשרות. עם *לא להציע*, או כששתי התוכניות אינן מותקנות, שום דבר אינו מציע
  *כ-root*.
- *השאר root פתוח בזמן סרק* הוא מספר הדקות שגישת root נשארת פתוחה אחרי הפעולה האחרונה שלה. עם `0` היא נסגרת
  מיד כשכל פעולה מסתיימת.

כש-Navigator כבר רץ כ-root, שום דבר אינו מוצע: כל פעולה היא של root.
