# Запуск Navigator

Команда называется `nav`:

```sh
nav [LEFT] [RIGHT] [options]
```

`LEFT` и `RIGHT` — каталоги, которые открываются в двух панелях. Если указан один, обе панели открываются в нём;
если ни одного — обе открываются в текущем каталоге. Любой из них может быть адресом места помимо диска, например
`sftp://user@host/dir`, `ftp://host/`, `smb://host/share` или `s3://s3.amazonaws.com/bucket`; см.
[Места помимо диска](drives.md).

Параметр, заданный в командной строке, действует только в этом сеансе. Он главнее [настроек](settings.md) и
никогда в них не записывается.

## Файлы и места

| Параметр | Что делает |
|---|---|
| `-e FILE`, `--edit FILE` | Открывает файл в [редакторе](editor.md) при запуске. Укажите его несколько раз, чтобы открыть несколько файлов. Файл с ещё не существующим именем создаётся при сохранении |
| `--config PATH` | Читает и сохраняет настройки в другом файле вместо `~/.config/navigator/navigator.ini` |
| `--database PATH` | Хранит истории и закладки в другом файле вместо `~/.local/state/navigator/navigator.db` |
| `--version` | Печатает версию и то, какая копия Navigator установлена, и завершается |

Файлы, лежащие рядом с `navigator.ini`, — [меню пользователя и связи файлов](user-menu.md), назначения клавиш,
палитры — с `--config` не переносятся: они остаются в `~/.config/navigator`.

## Цвета и символы

| Параметр | Что делает |
|---|---|
| `--theme NAME` | Использует другую цветовую схему |
| `--list-themes` | Печатает названия цветовых схем и завершается |
| `--palette dos` | Показывает каждый цвет так, как его показывала VGA-карта DOS Navigator, независимо от цветовой схемы самого терминала |
| `--palette terminal` | Оставляет шестнадцать цветов цветовой схеме самого терминала |
| `--reprogram-palette` | На время работы Navigator устанавливает шестнадцать цветов терминала как в DOS — для терминала, которому иначе цвета не задать |
| `--colors DEPTH` | Сколько цветов показывает терминал: `mono`, `8`, `16`, `256` или `truecolor`. `auto` определяет по `$COLORTERM` и `$TERM` |
| `--glyphs SET` | Какие символы рисует шрифт терминала: `ascii` рисует рамки знаками `+` и `-`, `unicode` рисует рамки псевдографикой, `nerd` добавляет значок рядом с каждым именем файла для шрифта Nerd Font. `auto` угадывает |
| `--marks LOOK` | Как выглядят флажки и переключатели: `dos` — это `[X]` и `(•)`, `brackets` — `[✓]` и `(●)`, у `boxes` нет скобок |
| `--charset NAME` | Кодировка терминала, работающего не в UTF-8, например `koi8-r`, `cp866` или `iso8859-2`. Без него используется кодировка локали |
| `--graphics HOW` | Как программа просмотра рисует картинку: `kitty`, `sixel` или `none`, чтобы показать её байты. Без него спрашивается терминал |
| `--no-dim-modal` | Оставляет то, что позади диалогового окна, в полном цвете, а не бледным; `--dim-modal` снова включает бледность |

Подробнее о темах — в разделе [Клавиши и цвета](customizing.md#цвета).

## Язык и направление

| Параметр | Что делает |
|---|---|
| `--language CODE` | Язык надписей и сообщений, например `lv`, `ru`, `ja` или `en`. Без него используется *Язык* из настроек, а иначе `$LANG` |
| `--direction auto` | Отражает экран, когда язык пишется справа налево, как иврит или арабский. Без параметра используется *Направление* из настроек, которое изначально равно этому |
| `--direction rtl` | Отражает экран при любом языке, чтобы он читался справа налево |
| `--direction ltr` | Никогда не отражает экран |
| `--bidi app` | Navigator сам раскладывает текст справа налево перед отправкой. Без параметра терминал распознаётся и выбирается правильный способ |
| `--bidi words` | Каждое слово, пишущееся справа налево, отправляется перевёрнутым — для терминала вроде kitty, который переворачивает его обратно |

Те же параметры есть на странице [Интерфейс](settings.md#интерфейс) настроек.

## Когда что-то идёт не так

| Параметр | Что делает |
|---|---|
| `--on-error dialog` | Неожиданная ошибка показывает окно с подробностями, и можно продолжать работу |
| `--on-error crash` | Неожиданная ошибка завершает Navigator и печатает подробности |

В обоих случаях ошибка добавляется в `errors.log` рядом с базой данных: в `~/.local/state/navigator` или в
каталоге, указанном в `--database`. На странице [Система](settings.md#система) настроек есть тот же выбор.

## Внутри Navigator

Если набрать `nav` в командной строке самого Navigator, вторая копия не запустится: он сообщит, что Navigator уже
работает и что `Ctrl+O` возвращает к нему.
