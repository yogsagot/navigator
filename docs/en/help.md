# Help on help

`F1` opens this manual on the page about what you are doing. The pages are linked to each other: a link is shown
in its own colour, and one of them is always the selected one.

## Keys

| Key | What it does |
|---|---|
| `Tab` | Select the next link |
| `Shift+Tab` | Select the previous link |
| `Enter` | Go to the selected link |
| `Alt+F1` | Go back to where you came from |
| `Shift+F1` | Open the [contents](README.md) |
| `F1` | Open this page |
| `Up`, `Down`, `PgUp`, `PgDn`, `Home`, `End` | Scroll the page |
| `Alt+Z` | Zoom the window to the whole screen, and back |
| `Esc` | Close Help |

## The mouse

Click a link to go to it. The wheel scrolls the page, and so does the bar on the right edge of the window when the
page is longer than the window.

## Links to other sites

A link that leads out of this manual, to a web site, is not followed by Navigator. Your terminal may open it: in
most terminals hold `Ctrl` and click it.
