# Help on help

`F1` opens this manual on the page about what you are doing. The pages are linked to each other: a link is shown
in its own colour, and one of them is always the selected one.

## Help where you are

`F1` works everywhere, and opens the page about what has the keyboard:

- in a dialog box, the section about that box. Many boxes also have a *Help* button that does the same;
- in an open menu, the page about the highlighted entry, or about its menu;
- in a window, such as the viewer, the editor or the calculator, that window's page;
- in the panels, the page about panels.

Where no page is about what you are doing, the [contents](README.md) open. `Esc` closes Help and leaves you where
you were, with a menu still open if one was. While a program runs in the console, `F1` is that program's.

## Keys

| Key | What it does |
|---|---|
| `Tab` | Select the next link |
| `Shift+Tab` | Select the previous link |
| `Enter` | Go to the selected link |
| `Alt+F1` | Go back to where you came from |
| `Shift+F1` | Open the [contents](README.md) |
| `F1` | Open this page |
| `Up`, `Down`, `PgUp`, `PgDn`, `Home`, `End` | Scroll the page |
| `Left`, `Right` | Scroll sideways, when a line of code is wider than the window |
| `Alt+Z` | Zoom the window to the whole screen, and back |
| `Ctrl+F5` | Move and size the window: the arrows move it, `Shift` and the arrows size it, `Enter` keeps it there, `Esc` puts it back |
| `Esc` | Close Help |

These keys can be changed: Options > Configuration > Key bindings, under *Help window*.

## The mouse

Click a link to go to it. The wheel scrolls the page, and so does the bar on the right edge of the window when the
page is longer than the window. A page with a line of code wider than the window has a bar along the bottom edge
too; `Shift` and the wheel scroll it sideways.

## Links to other sites

A link that leads out of this manual, to a web site, is not followed by Navigator. Your terminal may open it: in
most terminals hold `Ctrl` and click it.
