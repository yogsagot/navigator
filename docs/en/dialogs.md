# Dialog boxes

A dialog box holds the keyboard until you close it.

## Keys in a dialog box

| Key | What it does |
|---|---|
| `Tab`, `Shift+Tab` | Go to the next or the previous control |
| `Alt` and a highlighted letter | Go to the control with that letter |
| `Enter` | Press the default button, the one marked with arrows |
| `Esc` | Close the box without doing anything |
| `Space` | Tick a box, or choose a radio button |
| `Down` on a line with a `↓` beside it | Open the line's history |
| `F1` | Show the help for this box |

In a history list, `Enter` takes an entry and `Del` forgets it.

## Choosing a file

Several commands ask for a file with the same box: the name on a line, and under it the files and the directories
of the place being looked at.

- *Name* is the file's name. You can type a whole path. A name with `*` or `?`, or the name of a directory, lists
  those files instead of choosing one.
- *Files* lists the files that match. Typing letters there finds a name that starts with them.
- *Directories* lists the directories; `Enter` on one goes into it.
- The pane at the bottom shows the path, and the size and date of the file under the cursor.
- *OK*, or `Enter` on a file, chooses it.

`Left` and `Right` move between the lists and the buttons.
