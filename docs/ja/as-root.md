# root としての作業

ディスク上の操作が権限不足で拒否されたとき、Navigator はそれを root としてやり直せます。パスワードは `sudo` を通じて尋ねるか、
`pkexec` に尋ねさせます。パスワードは保存されませんが、root アクセスは最後の操作から数分間開いたままになり、Navigator の終了時に閉じます。

## root として実行するかの確認

コピー、移動、削除、名前の変更、ディレクトリやリンクの作成、属性の変更、エディタでの保存、ファイルの読み込みが拒否されると、
メッセージに *root として* が表示されます。コピーや削除のように続けるファイルがまだある場合は *省略* と *取消* の横に、それ以外は
*取消* だけの横にあります。これを選んでパスワードを入力すると、その操作は root としてやり直されます。同じ操作のそれ以降の操作も、
再び尋ねることなく root として行われます。

読み取りを許されていないディレクトリに入るときも、同じ確認が出ます。応じると、パネルは root としてそのディレクトリを一覧します。
パスは `root:///path` と表示され、コピー、削除、表示、編集などは他の場所と同じように使えます。*パネル化* や *ハードリンクを表示* のように、
root ではなく自分として実行されるコマンドは、そこでは灰色になります。読み取りを許されているディレクトリへ上がると、パネルはディスクに戻ります。

## root アクセス

*ツール > root 権限に昇格* は、パスワードを一度だけ尋ねて root アクセスを開いたままにします。閉じるまでは、読み取りを許されていない
ディレクトリも尋ねることなく root として開き、[コンソール](console.md)はパネルに追従する root のシェルを実行します。開いているあいだは、
メニューバーの時計の横に *ROOT* が表示され、メニューバーが隠れているときやコンソールを表示しているときはキーバーに表示されます。

*ツール > root アクセスを閉じる* (root アクセスが開いているあいだに名前が変わる同じ項目)、または *ROOT* のクリックで閉じます。
root として表示していたパネルはディスクに戻り、コンソールは自分のシェルに戻ります。

root アクセスは、しばらく使われないと自動的に閉じ、Navigator の終了時には必ず閉じます。

## 設定

設定の[システム](settings.md#システム)ページ:

- *root権限* は root になる方法を選びます。*自動* は `sudo` を、なければ `pkexec` を使います。*sudo* と *pkexec* はそれを使います。
  *提案しない* はオフにします。*提案しない* のとき、またはどちらのプログラムもインストールされていないときは、*root として* は提案されません。
- *待機中も root 保持* は、最後の操作の後に root アクセスを開いておく分数です。`0` では、各操作が終わるとすぐに閉じます。

Navigator をすでに root として実行している場合は、何も提案されません。すべての操作が root のものだからです。
