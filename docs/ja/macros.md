# マクロ

Navigator のマクロには 2 種類あります。どこでも記録して再生できるキーのマクロと、エディタ用にファイルに書くマクロです。

## キーマクロ

キーマクロは、入力したものを記録したものです。1 から 9 までの番号が付いた 9 つがあり、セッションをまたいで保存されます。

| キー | 動作 |
|---|---|
| `Ctrl+J` `R` `1` から `9` | そのマクロへの記録を始める |
| 記録中に `Ctrl+J` `R` と任意の数字 | 記録を止める |
| `Ctrl+J` `1` から `9` | そのマクロを再生する |

キーは 1 つずつ順に押します。`Ctrl+J`、次に `R`、次に数字です。マクロの記録中は、時計の横に `>MACRO<` が表示されます。

どのウィンドウやダイアログボックスでも、入力したものと貼り付けたものはすべて記録されます。ダイアログボックスが開いているあいだは
記録を始めることも止めることもできないので、記録を始めてからボックスを開き、止める前にボックスを閉じてください。

コンソールやコマンドウィンドウでプログラムが実行中のあいだは、`Ctrl+J` はそのプログラムに送られます。

## エディタのマクロ

エディタのマクロは、名前を付けたエディタコマンドの並びです。[エディタ](editor.md)で `Ctrl+J` `0` を押すと、編集中のファイル用の
マクロを一覧し、選んだものを再生します。

マクロは `macros.ini` にあり、*設定 > 構成 > マクロファイルの編集* で開きます。セクションは、そのマクロを使うファイルを `;` で区切った
マスクで指定します。`[*]` セクションはすべてのファイル用です。

```ini
[*]
MACRO Date and time
  InsertDate
  PRINT ' '
  InsertTime
ENDMACRO

[*.c;*.h]
MACRO Block
  PRINT '{'^M'}'
  MoveUp
ENDMACRO
```

マクロの各行は次のいずれかです。

| 行 | 動作 |
|---|---|
| `PRINT 'text', n` | テキストを `n` 回入力する。`n` は省略できる |
| `GOTOXY x, y` | カーソルを行 `y` の桁 `x` へ移す。どちらも 0 から数える |
| `GOTOX x`, `GOTOY y` | 桁だけ、または行だけを移す |
| `MARK n`, `GOTO n` | 1 から 9 のマーカー `n` を設定する、またはそこへ移る |
| `Command, n` | エディタコマンドを `n` 回実行する |

`PRINT` では、テキストを一重引用符で囲み、その中の `''` は引用符 1 つを表します。引用符の外では `^M` は制御文字 (この例では `Enter`) を、
`#13` はコードで指定した文字を表します。

コマンドは、`WordLeft`、`MoveUp`、`DelChar` のような DOS Navigator での名前か、`word_left` のような `keybindings.ini` での名前で書きます。
知られていない名前は飛ばされ、どれが飛ばされたかが知らされます。

`;` で始まる行はコメントです。
