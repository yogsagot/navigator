# 宏

Navigator 有两种宏：在任何地方录制和回放的按键，以及写在文件中供编辑器使用的宏。

## 按键宏

按键宏是对你输入内容的录制。共有九个，编号为 1 到 9，并在会话之间保留。

| 按键 | 作用 |
|---|---|
| `Ctrl+J` `R` `1` 到 `9` | 开始录制到该宏 |
| 录制时按 `Ctrl+J` `R` 和任意数字 | 停止录制 |
| `Ctrl+J` `1` 到 `9` | 回放该宏 |

依次按下这些键：先按 `Ctrl+J`，再按 `R`，然后按数字。录制宏时，时钟旁会显示 `>MACRO<`。

在任何窗口或对话框中输入的所有内容都会被录制，粘贴的内容也一样。对话框打开时不能开始或停止录制，因此请在开始录制后再打开对话框，并在停止录制前关闭它。

当控制台或命令窗口中有程序运行时，`Ctrl+J` 会发送给该程序。

## 编辑器宏

编辑器宏是一组带名称的编辑器命令。在[编辑器](editor.md)中按 `Ctrl+J` `0` 会列出适用于当前编辑文件的宏，并回放所选的宏。

宏保存在 `macros.ini` 中，可用 *选项 > 配置 > 编辑宏文件* 打开。每个节指定其中的宏适用于哪些文件，多个掩码用 `;` 分隔。`[*]` 节适用于所有文件。

```ini
[*]
MACRO Date and time
  InsertDate
  PRINT ' '
  InsertTime
ENDMACRO

[*.c;*.h]
MACRO Block
  PRINT '{'^M'}'
  MoveUp
ENDMACRO
```

宏的每一行是以下之一：

| 行 | 作用 |
|---|---|
| `PRINT 'text', n` | 输入该文本 `n` 次；`n` 可以省略 |
| `GOTOXY x, y` | 把光标移到第 `y` 行的第 `x` 列，二者都从 0 开始计数 |
| `GOTOX x`、`GOTOY y` | 只移到该列，或只移到该行 |
| `MARK n`、`GOTO n` | 设置标记 `n`（1 到 9），或转到该标记 |
| `Command, n` | 运行一个编辑器命令 `n` 次 |

在 `PRINT` 中，文本写在单引号内，其中的 `''` 表示一个单引号。在引号之外，`^M` 是一个控制字符（这里是 `Enter`），`#13` 是用编码给出的字符。

命令用 DOS Navigator 中的名称书写，例如 `WordLeft`、`MoveUp` 或 `DelChar`，也可以用 `keybindings.ini` 中的名称，例如 `word_left`。未知的名称会被跳过，并告诉你是哪一个。

以 `;` 开头的行是注释。
