# 以 root 身份工作

当磁盘上的某个步骤因权限不足而被拒绝时，Navigator 可以以 root 身份再执行一次。它通过 `sudo` 询问你的密码，或者让 `pkexec` 来询问。密码不会被保存，但 root 权限会在最后一个步骤之后保持打开几分钟，并在 Navigator 退出时关闭。

## 以 root 身份询问

当复制、移动、删除、重命名、创建目录或链接、更改属性、在编辑器中保存或读取文件被拒绝时，提示信息会提供 *以 root 身份*：如果还有更多文件要继续处理（例如复制或删除时），它与 *跳过* 和 *取消* 并列，否则只与 *取消* 并列。选择它并输入密码后，该步骤会以 root 身份重新执行——同一操作此后的每个步骤也都如此，不再询问。

进入你无权读取的目录时，也会出现同样的询问。回答后，面板以 root 身份列出该目录：其路径显示为 `root:///path`，复制、删除、查看、编辑等操作在那里与在其他地方一样可用。会以你本人而非 root 身份运行的命令，例如 *列入面板* 和 *显示硬链接*，在那里显示为灰色。向上进入你有权读取的目录时，面板会回到普通磁盘。

## root 权限

*工具 > 获取 root 权限* 询问一次密码，并保持 root 权限打开：在关闭之前，你无权读取的目录会直接以 root 身份打开而不再询问，[控制台](console.md)运行一个跟随面板的 root shell。root 权限打开期间，菜单栏上时钟旁会显示 *ROOT*；菜单栏隐藏或显示控制台时，则显示在按键栏上。

*工具 > 关闭 root 权限*——即 root 权限打开时被改名的同一菜单项——或单击 *ROOT* 会关闭它：以 root 身份浏览的面板回到普通磁盘，控制台回到你自己的 shell。

root 权限在一段时间未使用后也会自动关闭，并且在 Navigator 退出时总会关闭。

## 设置

在设置的[系统](settings.md#系统)页中：

- *root 权限* 选择如何成为 root：*自动* 使用 `sudo`，否则使用 `pkexec`；*sudo* 和 *pkexec* 使用对应的程序；*从不提供* 关闭此功能。选择 *从不提供*，或两个程序都未安装时，任何地方都不会提供 *以 root 身份*。
- *闲置时保持 root* 是 root 权限在最后一个步骤之后保持打开的分钟数。设为 `0` 时，每个操作结束后立即关闭。

如果已经以 root 身份运行 Navigator，则不会提供任何选项：每个步骤都以 root 身份执行。
