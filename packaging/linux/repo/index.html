Navigator

A recreation of the DOS Navigator two-panel file manager for POSIX terminals. This is its package repository; the source is on GitHub.

Debian, Ubuntu

Needs Ubuntu 24.04 or Debian 13 and later — Navigator wants Python 3.12.

sudo install -m 0755 -d /usr/share/keyrings
sudo curl -fsSL -o /usr/share/keyrings/navigator-fm-archive-keyring.gpg \
    https://yogsagot.github.io/navigator/navigator-fm-archive-keyring.gpg

sudo tee /etc/apt/sources.list.d/navigator-fm.sources > /dev/null <<'EOF'
Types: deb
URIs: https://yogsagot.github.io/navigator/deb
Suites: stable
Components: main
Architectures: all amd64 arm64
Signed-By: /usr/share/keyrings/navigator-fm-archive-keyring.gpg
EOF

sudo apt update && sudo apt install navigator-fm

Fedora, RHEL, Alma, Rocky

Needs Fedora 39 or RHEL 10 and later.

sudo rpm --import https://yogsagot.github.io/navigator/navigator-fm-archive-keyring.asc

sudo tee /etc/yum.repos.d/navigator-fm.repo > /dev/null <<'EOF'
[navigator-fm]
name=Navigator file manager
baseurl=https://yogsagot.github.io/navigator/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://yogsagot.github.io/navigator/navigator-fm-archive-keyring.asc
EOF

sudo dnf install navigator-fm

Anywhere else

Navigator is on PyPI as navigator-fm. This route does not update itself — that is the whole reason the repositories above exist. 

pipx install navigator-fm

Which copy am I running?

nav --version prints the directory it was imported from, not just the number. If Navigator is installed more than one way, ~/.local/bin comes before /usr/bin on most paths, so the copy that runs may not be the one you just installed. 

$ nav --version
nav 0.1.0 from /usr/lib/navigator-fm/navigator (python 3.12.3)
Everything here is signed. If apt update stops complaining after you delete the keyring, something is wrong — tell us.
