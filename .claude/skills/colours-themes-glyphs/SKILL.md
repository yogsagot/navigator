# Colours, themes and glyphs

## Themes are generated, never hand-edited

Colour is split from structure and neither half is authored by hand. `navigator/styles/navigator.nss` holds the rules
and defines no variable; `navigator/styles/themes/*.nss` define every variable and no rule, and one is always loaded
after it (`load_scheme("norton")`, `--theme norton`, `--list-themes`). `navigator/scheme.py` holds `load_scheme`,
`default_scheme` (parsed on first use, not at import) and `theme_names`. Each theme is a DN `COLORS/*.PAL` decoded by
`tools/palconv.py`, which documents the format and which of the 228 attribute bytes means what.

- Regenerate: `./venv/bin/python tools/palconv.py path/to/DN/COLORS --out navigator/styles/themes`; `--dump ONE.PAL`
  prints one palette's decoded slots.
- **For now only `default.nss` is edited**: after palconv regenerates, revert the other ten themes.
- **A deliberate departure from a palette goes in `palconv.py`'s `DEPARTURES`** (theme -> slot -> colours and why),
  applied on generation and marked in the theme's comment. Current: `default` [117], the viewer's *Normal text*, is
  #D8D8D8 at the user's request (DEFAULT.PAL's was 2.6:1 contrast).
- The slot table comes from `RESOURCE/ENGLISH/DN.DNR` (`COLORITEM <name>, <index>` lines; CP437, decode before
  grepping): all 144 entries the Colors dialog exposes, in 20 nested groups. `palconv.py --names path/to/DN.DNR`
  regenerates it. Twenty-three entries independently agree with the Turbo Vision palette-string chain, which is what
  makes the other 121 trustworthy. The 84 entries DN.DNR does not name are not carried.
- Every theme carries all 144; `navigator.nss` reads some (`LIVE` marks them with `>`). Variables are stemmed by group
  *path* (group names repeat); **a published variable name is API** -- `HAND_NAMED` pins the ones `navigator.nss` uses.
- Variables Navigator needs and DN had no slot for are palconv's **`DERIVED`** table, each an alias of a slot, with
  `DERIVED_DEPARTURES` for a theme that wants otherwise (`default`'s `symlink` and `temp`).

## File-type colours

`navigator/filetypes.py`'s `category_of`: Midnight Commander's type classes off the type mark (`executable`, `symlink`,
`stale-link`, `device`, `special`) or else DN's categories by mask (`archive`, `image`, `media`, `document`, `source`,
`temp`), one class on `Panel::row` beside `.directory`, **the type winning** as it does for the icon; a directory takes no
category. The rules sit between `.directory` and the cursor/tag rules in `navigator.nss`, so the cursor and a tag
still win. Executables [173] and Archives [174] are DN's slots; the rest are `DERIVED` aliases of DN's Custom 1-5
[175-181]. `filetypes.matches` is also what *Select group* reads masks with.

## The palette stays exact; the edge quantises

A widget asks for the colour it wants and a sheet records the colour the original asked for; `render_diff(previous,
current, info)` quantises to what the terminal can name -- **the only place the question is asked**. A palette *index*
passes through untouched unless a palette is pinned: unset (navkit's default), `blue` is the user's terminal theme's;
with `VGA_PALETTE` it means the DOS register value. `navigator` pins by default; `--palette terminal` hands the question
back. **A child program's cells are never pinned** (`Style.terminal_palette`, per cell, not a sheet field, and `adapt_style` leaves their indices alone), so
`ls --color` in the console matches the plain terminal. Pinning is a no-op below 256 colours; `--reprogram-palette`
(OSC 4, reset with OSC 104) reaches those. `NAVKIT_PALETTE` (`dos`/`vga`, `terminal`/`none`/`off`) overrides;
`--palette` outranks it.

## Glyphs

`TerminalInfo.glyphs`: `GLYPHS_ASCII` < `GLYPHS_UNICODE` < `GLYPHS_NERD`; `NAVKIT_GLYPHS` overrides and `--glyphs
{auto,ascii,unicode,nerd}` outranks it. **A font cannot be detected**, so the Nerd tier is granted only to emulators
that bundle a Nerd Font fallback (kitty, WezTerm, Ghostty) or a session that says so; a multiplexer needs the override.
A non-UTF-8 locale gets ASCII. `navkit/glyphs.py` holds the frame sets (`single`, `double`, `round`, `ascii`) and imports
nothing; `draw_box` takes six characters, never a name; `Widget.box_charset()` resolves the sheet's wish against the
tier. `Widget.box_joins()` matches tees (`┬┴` single, `╤╧` double).

**The Nerd Font icon gutter in `Panel` is the project's one standing modern exception**, taken deliberately, on only
where the font is known to exist, reversible with `icons: none` or `--glyphs unicode`. Don't re-litigate it and don't
read it as licence for the next flourish. Icons: `icons.BY_TYPE` beats the extension's;
`icons.HIDDEN_FILE`/`HIDDEN_FOLDER` for unclaimed dot-names.
